# logos

Programming language logos (SVG) used in the READMEs of my other repositories.

| File | Language |
|---|---|
| `c_logo.svg` | C |
| `cpp_logo.svg` | C++ |
| `java_logo.svg` | Java |
| `javascript_logo.svg` | JavaScript |
| `python_logo.svg` | Python |
| `typescript_logo.svg` | TypeScript |

Usage in a README:

```html
<img src="https://raw.githubusercontent.com/jerichd4c/logos/main/python_logo.svg" alt="Logo" width="80" height="80">
```

This repository must stay public: the logos are loaded from `raw.githubusercontent.com`, which does not serve files from private repositories.
